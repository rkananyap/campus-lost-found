# campus-lost-found
Campus Lost &amp; Found is a full-stack web application that digitizes lost and found item management across a college campus. Built with HTML, CSS, JavaScript, Node.js, Express.js, and MySQL, it features secure authentication, CRUD operations, REST APIs, search and filtering, session management, and real-time item recovery status tracking
# 🎓 Campus Lost & Found

A full-stack web application designed to digitize and streamline the management of lost and found items within a college campus.

## 🚀 Features

- 🔐 User Authentication
- 📋 Report Lost and Found Items
- 🗄️ MySQL Database Integration
- 🔄 CRUD Operations
- 🔎 Search and Filtering
- 📊 History and Item Details
- ✅ Item Recovery Status Tracking
- 🔑 Password Hashing using bcrypt
- 🌐 RESTful APIs
- 💻 Responsive User Interface

## 🛠️ Tech Stack

### Frontend
- HTML5
- CSS3
- JavaScript

### Backend
- Node.js
- Express.js
- REST APIs
- Express Session

### Database
- MySQL

### Security
- bcrypt Password Hashing
- Session-based Authentication
